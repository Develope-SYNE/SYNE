# 앨범 커버: 주행 데이터 → 커버 요소 대응표

커버는 곡이 끝날 때(기어 P 이후) 한 번만 만들고 저장한다. 이후 보관함·모바일은 같은 파일을 읽기만 한다.
앱 UI(검정·흰색·파랑·금빛)와 커버는 일부러 다른 시각 언어를 쓴다 — 커버는 인디 아티스트의 앨범처럼 곡마다 다르다.
**좌표는 쓰지 않는다.** 경로는 1초 기록(속도·조향)을 적분해 만든 '모양'만 쓴다. 그림(매체) 안에는 글자·로고·지도를 넣지 않고, 모든 커버에 같은 형식의 '서명'(경로 선 + SYNE · Vol.n)만 앱이 얹는다.

코드: `app/src/main/java/ai/syne/app/cover/`
`ArtDirections`(무드 경향) → `ArtBrief.from`(기록 → 설계서) → `ArtPainters`(기기 안) / `RemoteCoverGenerator`(선택) → `CoverSignature`(서명) → `CoverStore`

## 대응표

| 주행 데이터 | 출처 | 커버 요소 | 어떻게 |
|---|---|---|---|
| 장르(무드) | 홈에서 고른 장르 | **스타일(매체) 경향** | 18개 매체 중 무드별 가중치. Lo-fi: 필름 사진·수채·리소·잉크 / Hip-hop: 콜라주·스트리트·하드 라이트 / (City Pop·Ambient 경향도 정의됨). 어떤 무드든 모든 매체가 낮은 확률로 나올 수 있다 |
| 최근 같은 무드 커버 3장 | 저장된 `art2:` 태그 | **스타일(반복 방지)** | 최근 3곡과 같은 매체는 제외 |
| 출발 시각 | 곡 시작 시각 | **색(빛)** · 스타일 | 새벽(옅은 빛) / 낮(부드러운 하늘) / 해질녘(금빛) / 밤(깊은 남색). 밤에는 밤 불빛·네온 매체 가중치 ↑, 낮에는 수채·안개 ↑ |
| 계절 | 곡 시작 월 | **색 온도** | 봄 분홍빛 · 여름 초록빛 · 가을 주황빛 · 겨울 회청빛 틴트 |
| 곡 길이 | 엔딩까지의 곡 시간 | **구도(밀도)** | 길수록 장면의 요소(건물·도형·붓질)가 많아진다 |
| 부드러움(평균) | DriveState 부드러움 지수 | **질감** · 스타일 | 높을수록 깨끗하고 차분(안개·수평선·컬러 필드 ↑), 낮을수록 거친 입자·흔들리는 선(콜라주·유화 ↑) |
| 급제동 횟수 | DriveState | **긴장감** | 찢김·대비·흘러내림이 늘고, 콜라주·스트리트·하드 라이트 가중치 ↑ |
| 정차 빈도(정차/km) | 1초 속도 기록 | 스타일 | 잦으면(도심) 밤 불빛·네온·필름 사진 ↑ |
| 주행 거리 | 1초 속도 적분 | 스타일 | 5km 넘으면 풍경(안개·수평선·수채) ↑ |
| 가감속 출렁임 | 1초 속도 변화량 | 스타일 | 크면 기하 팝·유화 ↑ |
| 멜로디 윤곽 | 조향 멜로디 노트(MIDI) | **구도(리듬)** | 8구간 평균 음높이 → 능선 높이·건물 높이·도형 크기의 리듬 |
| **경로 모양** | 1초 속도 × 조향 적분(자전거 모델) | **서명: 경로 선** | 아래 참조 — 모든 커버에 같은 형식으로 선명하게 |
| Vol 번호 | 코스 앨범 안 순서 | **서명: SYNE · Vol.n** | 오른쪽 아래 작은 글자 |
| 출발 시각 × 노트 합 | — | 시드 | 같은 곡은 언제 다시 그려도 같은 커버(재현 가능) |

## 서명(모든 커버 공통)

스타일(매체)은 곡마다 달라도, 모든 커버에 같은 형식의 서명이 얹힌다 — 기기 페인터와 AI 서버 생성 이미지 모두(`CoverSignature`).

| 요소 | 형식 |
|---|---|
| 경로 선 | `RouteShape`(호 길이 등간격 48점, 0~1 정규화)를 가운데 64% 상자에. **얇은 선(3.2/1024) + 은은한 금빛 글로우**, 출발 = 작은 점, 도착 = 금빛 고리 |
| 대비 자동 조정 | 선이 지나는 자리의 평균 밝기 < 0.55 → **흰 선**, 그 이상 → **먹색 선**. 선 아래에 반대색 얇은 그늘(35%)을 깔아 복잡한 그림에서도 선명 |
| 표기 | 오른쪽 아래 **"SYNE · Vol.n"**(Pretendard SemiBold, 26/1024, 자간 0.12) — 배경 밝기에 따라 흰/먹색 + 반대색 그늘 |

50m 미만 주행은 경로 선 없이 표기만 들어간다. 경로 선은 위치·크기·방향 정보가 없는 '모양'이다.

## 생성 경로

| 경로 | 상태 | 비고 |
|---|---|---|
| 기기 안 페인터(`ArtPainters`) | **동작** | 모든 커버가 현재 이 경로로 그려진다 |
| 이미지 생성 서버(`RemoteCoverGenerator`) | 연결 안 됨 | `-Psyne.coverServer=<URL>`로 빌드하면 곡이 끝난 뒤 프롬프트·시드·크기만 전송(좌표·장소 이름 없음). 실패 시 기기 커버 유지 |

기존에 저장된 커버는 다시 그리지 않는다(시연 전 데이터 초기화 예정). 서명은 이 규칙이 들어간 뒤 만들어지는 곡부터 들어간다.
