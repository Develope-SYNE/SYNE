# SYNE 기능 명세 (MVP 우선순위)

## P0 — 11/15 제출 전
1. 신호 계층: RealSignals(조향·브레이크·방향지시등·속도·기어·내비) / ReplaySignals(assets/trip_demo.json, 10Hz)
   - Replay 중에도 Virtual Console의 조향·브레이크 입력을 덮어써서 실시간 반응 시연
2. DriveState: 1초 샘플 기록, 부드러움 지수 0~100(가감속 변화율·조향 변화율·급제동 기반)
3. SoundEngine: 장르 팩 1종(Lo-fi), 스템 6~8개 동기 루프
   - 속도 구간 → 편성(정차: pad / 저속: +bass·drum / 중속: +keys / 고속: +lead)
   - 조향 → 리드 음정(스케일 내 양자화)·패닝 / 급제동 → 한 마디 끊김(필터 스윕·드롭)
   - 방향지시등 → 하이햇 액센트 / 제한속도 초과 → 편성 축소
   - 템포 고정(예: 84 BPM), 마디 경계에서만 전환
4. SongPlanner: 남은 시간 → 인트로/전개/클라이맥스/피날레 배분, 기어 P → 피날레 후 종료
5. 기록: 주행 중 리드 멜로디 노트 로그(MIDI 유사 JSON) + 30초 하이라이트 녹음
6. 보관함(Room): 출발·도착 좌표를 반경 300m 클러스터로 묶어 코스 키 생성 → 같은 코스 = 같은 앨범(Vol.n)
   - 장르는 태그 → 자동 플레이리스트
7. 커버: 오프라인 기본 커버(정규화 경로 폴리라인 + 속도 색) / 서버 AI 커버 호출(P 이후)
8. UI: 정차 화면(장르 선택·보관함·트랙 상세), 주행 화면(고정 레이아웃, 숫자·파형 정적 갱신만)
   - 주행 화면 배치 제약(2026-11-02 에뮬레이터 확인): 방향지시등 ON 시 시스템이 측방(사각지대) 카메라 팝업을
     앱 영역 왼쪽 상단(약 앱 폭의 45% × 높이의 35%)에 띄운다. 이 영역에는 핵심 정보(현재 구간·곡 진행·경고)를 두지 말 것.
     → 핵심 정보는 오른쪽·하단, 왼쪽 상단은 장식(커버 아트·파형 배경)만.
   - 갱신 빈도: 주행 중(P 아님) 1Hz 이하, 정차 중에만 10Hz.

## P1 — 12/3 2차 PT 전
- AI 완성곡: 멜로디 로그 → 서버(MusicGen-melody) → 선택 장르 1분 트랙
- 장르 팩 추가(시티팝·앰비언트), AI 앨범 이름 제안, 내비 TBT 기반 회전 전 곡 전환

## 서버 (server/)
- POST /cover  {routeShape:[[x,y]...0~1 정규화], genre, timeOfDay, smoothness} → image/png
  - 경로 폴리라인 → 스케치 이미지 → SDXL + ControlNet(scribble/lineart)
- POST /song   {melody:[{t,pitch,dur}], genre, seconds:60} → audio (P1)
- 시연 안정성: 서버 실패 시 앱은 오프라인 커버로 즉시 대체
