# 시연 영상 녹화 순서

Pleos Connect 에뮬레이터 v2.1.0(운전자 user 10), 제출용 release APK(`apk/SYNE_release.apk`) 기준.
아래 시각은 2026-11-09 같은 조건(Lo-fi · 코스 A)으로 데모 주행을 두 번 돌려 SYNE 로그와 화면 녹화로 잰 값이다.
두 번의 차이는 0.2초 안이었다.

## 0. 녹화 전 상태 (2026-11-09 준비 완료)

| 항목 | 상태 |
|---|---|
| 설치된 앱 | `ai.syne.app` release(= `apk/` 파일과 같은 해시)만. bench 빌드(`ai.syne.app.bench`) 제거 |
| 데이터 | RELEASE.md 5절대로 초기화한 뒤 아래 3곡만 만들어 둠. 다운로드/SYNE 의 `.syne` 파일도 지움 |
| 권한 | 차속(`CAR_SPEED`)·알림(`POST_NOTIFICATIONS`) 미리 허용 → 녹화 중 권한 창 안 뜸 |
| 보관함 | ① 코스 A `분당구 삼평동 → 판교역 사무실` **Vol.1 · Lo-fi**, **Vol.2 · Lo-fi**  ② 코스 B `판교역 사무실 → 정자동 카페` **Vol.1 · Lo-fi** |
| 홈 화면 | Lo-fi · 코스 A 선택, 목적지 칸은 기본 문구("내비에서 목적지를 정해 주세요") |
| 소리 | 미디어 볼륨 최대(차량 오디오 MUSIC 그룹 45/45, `STREAM_MUSIC` 15/15) |

녹화하면서 실행하는 코스 A 주행이 **Vol.3 · Lo-fi**가 된다.

녹화 도구 주의: `adb shell screenrecord`는 **소리를 녹음하지 않고 최대 3분**이다. SYNE는 소리가 핵심이므로 Mac 쪽에서 화면과 시스템 소리를 함께 녹화한다(Mac 출력 볼륨도 확인).

## 1. 녹화 순서

1. **홈** — 제목 "오늘의 움직임을 음악으로.", 장르 카드, 오른쪽 시그니처 그래픽을 2~3초 보여 준다.
2. **Lo-fi · 코스 A 선택** — 장르 `Lo-fi` 카드 → 머리줄 `코스 A`를 누른다(이미 선택돼 있지만 화면에 보이도록 다시 누른다). 코스 A를 고르면 목적지 칸이 "판교역 사무실"로 바뀐다.
3. **데모 주행** — 머리줄 `▶ 데모 주행`을 누른다. **이 순간이 아래 표의 0:00**이다.
4. **주행** — 0:05에 주행 화면으로 바뀐다. 주행 화면은 원칙 1에 따라 **고정 그래픽**(코스 이름 + "Vol.3 · Lo-fi")이라 이벤트가 화면에 표시되지 않는다. 이벤트는 **소리로만** 드러나므로 편집할 때 아래 시각에 자막을 넣는다.
5. **도착 화면** — 2:13쯤 "주행 완료" 화면이 자동으로 열린다. 2:26쯤 저장이 끝나면 하이라이트 재생 버튼을 눌러 30초 하이라이트를 들려 준다.
6. **보관함** — 도착 화면 오른쪽 위 `보관함` → Vol.3이 맨 앞에 추가된 것과 코스 A 앨범(Vol.1~3)·코스 B 앨범을 보여 준다.

## 2. 이벤트 시각 (`데모 주행`을 누른 때 = 0:00)

| 시각 | 이벤트 | 주행 데이터(코스 A) | 들리는 것 / 보이는 것 |
|---|---|---|---|
| 0:00 | 데모 주행 시작 | 기어 P | 홈 화면 그대로, 시작 버튼이 `사운드 멈추기`로 바뀜. 인트로 패드가 깔린다 |
| 0:05 | 기어 D | 브레이크 밟은 채 D | **주행 화면으로 전환**(0:05~0:06) |
| **0:08 → 0:11** | **출발** | 0:08 바퀴가 구르기 시작, 0:11 시속 5km 넘음 | 0:11 킥과 함께 드럼이 들어온다 → 0:12 멜로디·베이스 → 0:14 전체 밴드(전개) |
| **0:18 → 0:23~0:29** | **좌회전** | 0:18~0:25 왼쪽 깜빡이, 0:23 핸들 왼쪽 → 0:25~0:26 최대(-112°) → 0:29 정면 | 핸들을 따라가는 조향 멜로디 |
| **0:45 → 0:52** | **정차**(신호) | 0:45 브레이크(50km/h) → 0:53 정지, 0:58까지 정지 | 0:45부터 키·멜로디가 잦아들고, 0:52 드럼·베이스가 빠지고 패드 + 잔향만 남는다 |
| 0:58 → 1:00 | 재출발 | 0:58 오른쪽 깜빡이와 함께 출발, 제한속도 70 | 1:00 킥과 함께 드럼 재시작, 1:06 멜로디가 밝은 lead 음색으로 |
| **1:13 ~ 1:20** | **과속** | 1:13 71km/h > 제한 70 → 1:14 최고 76km/h | 1:13 즉시 낡은 테이프처럼 먹먹해지고(로우패스·흔들림·지직거림) 멜로디가 빠진다. 1:20 제한 아래로 내려오면 1마디에 걸쳐 맑아진다 |
| **1:20 → 1:21** | **급제동** | 1:20 76km/h에서 강하게 제동(약 6m/s²) | 1:21 **테이프 스톱**(곡이 늘어지며 멈춤) → 1:22.5 리버스 심벌 → 1:23 전체 레이어가 한꺼번에 다시 들어온다 |
| 1:24 ~ 1:32 | 우회전 | 오른쪽 깜빡이, 핸들 오른쪽 | 조향 멜로디 |
| 1:40 | 피날레 시작 | | 곡이 마지막 구간으로 |
| 1:43 ~ 1:48 | 과속(어린이 보호구역 30) | 40km/h > 제한 30 | 1:13과 같은 먹먹함 → 1:48 복구 |
| **1:46 → 1:55** | **도착** | 1:46 브레이크 → 1:55 정지 → 기어 P | 1:54 드럼·베이스가 빠지고, P가 되면 **홈 화면으로 돌아온다**(1:56). 홈에는 "곡이 흐르고 있어요…" / "도착했어요. 곡을 마무리하는 중입니다."가 뜬다 |
| 1:58 ~ 2:09 | 엔딩 | | 엔딩 4마디(종지) → 2:09부터 2초 페이드 + 0.5초 무음 |
| **2:13** | **도착 화면** | | "주행 완료 · 오늘의 주행이 작품이 되었습니다." · Vol.3 · Lo-fi · 부드러움 88~89% · 1.0km · 2:11 · 급제동 1회 |
| 2:26 | 저장 완료 | | "앨범 저장 완료 · 보관함에 담겼어요", 커버 완성, 하이라이트(도착 직전 30초) 재생 가능 |

- 굵게 표시한 행이 자막을 넣을 6개 이벤트다. "→"는 데이터상 시작 → 소리가 바뀌는 시각.
- 에뮬레이터 오디오가 0.5~0.85초 끊길 때가 있다(RELEASE.md 6절, HAL 정지). 엔진이 곡 시간을 다시 맞추므로 위 시각은 밀리지 않지만 그 순간은 들리는 끊김이다. 크게 걸리면 다시 녹화한다.

## 3. 녹화 중 하지 말 것

- 0:00~0:05, 1:56~2:13 홈 화면이 보일 때 `사운드 멈추기`를 누르지 않는다(곡이 중간에 끊긴다).
- 도착 화면이 열리기 전(2:13 전)에 `보관함`을 누르지 않는다. 저장이 끝나기 전(2:26 전)에 보관함으로 가면 Vol.3 커버가 아직 없을 수 있다.
- 홈에서 `코스 B`를 누르지 않는다(데모 코스가 바뀐다).

## 4. 다시 준비하려면

1. RELEASE.md 5절(초기화 + bench 제거 + 권한 2개 허용)
2. 앱을 열고 Lo-fi · 코스 A로 `데모 주행` 2회 → Vol.1·Vol.2, 코스 B 1회 → 코스 B 앨범. 회당 도착 화면이 열리고 저장이 끝날 때까지 약 2분 30초. 다음 주행은 도착 화면 `홈`에서 시작
3. 코스 A를 다시 고르고 앱을 다시 실행(`am force-stop` → `am start`)하면 목적지 칸이 기본 문구로 돌아간다
4. 미디어 볼륨 최대: Pleos 에뮬레이터의 `cmd car_service`에는 볼륨 명령이 없다. 볼륨 키로 올린다

```bash
for i in $(seq 1 30); do adb shell input keyevent KEYCODE_VOLUME_UP; done
adb shell dumpsys car_service --services CarAudioService | grep -m1 "Gain indexes"   # … 0 45 20 45 (현재 45 = 최대)
```
